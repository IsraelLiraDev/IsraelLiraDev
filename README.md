### 3. BibliaPlay — PWA bíblica con experiencia de streaming

<p>
  <a href="https://play.clientesvip.es">
    <img src="https://img.shields.io/badge/Probar_demo-00A884?style=for-the-badge&logo=googlechrome&logoColor=white" alt="Probar BibliaPlay"/>
  </a>
  <a href="https://github.com/IsraelLiraDev/bibliaplay">
    <img src="https://img.shields.io/badge/Ver_repositorio-181717?style=for-the-badge&logo=github&logoColor=white" alt="Ver repositorio de BibliaPlay"/>
  </a>
</p>

Aplicación bíblica desarrollada como una plataforma de streaming: permite leer y escuchar la Biblia versículo a versículo, guardar el progreso y las notas, crear perfiles y descubrir música de alabanza relacionada con los pasajes. Es un producto real en producción, diseñado para móvil e instalable como PWA, con interfaz en portugués, español e inglés.

- 📖 **Lectura bíblica:** 66 libros y 1.189 capítulos, varias traducciones, búsqueda de texto completo, versículo del día y progreso de lectura.
- 📝 **Personalización y estudio:** hasta 5 perfiles por cuenta, notas por versículo o capítulo, favoritos, listas guardadas y sincronización entre dispositivos.
- 🔊 **Audio versículo a versículo:** lectura con resaltado sincronizado, controles de reproducción, velocidad ajustable y voces en varios idiomas.
- 🎵 **Música de alabanza:** recomendaciones temáticas vinculadas a capítulos y versículos, reproductor integrado, historial, favoritos y mini reproductor flotante.
- 🔔 **Notificaciones push:** versículo del día con horario y zona horaria configurables.
- 📱 **Experiencia móvil:** PWA con *service worker*, caché del shell y preparación de la app iOS mediante Capacitor y Codemagic.
- 🔐 **Seguridad:** contraseñas protegidas con `scrypt`, sesiones mediante cookies `HttpOnly` y `SameSite`, protección CSRF, limitación de peticiones y acceso a datos por perfil.
- ☁️ **Integraciones e infraestructura:** YouTube Data API v3, Google Cloud Text-to-Speech opcional, servicio TTS en Python y despliegue en VPS Linux con PM2.
- 💡 **Optimización de costes:** caché en PostgreSQL, control de cuota de YouTube, deduplicación de solicitudes y límite configurable para el servicio TTS de pago.

**Stack tecnológico:** JavaScript ES Modules · HTML5 · CSS3 · Node.js 22 · PostgreSQL · Python · edge-tts · Kokoro · Google Cloud TTS · YouTube Data API v3 · Web Push/VAPID · PWA · Capacitor · Codemagic · PM2 · Debian/Linux.

**Arquitectura:** frontend sin frameworks ni proceso de compilación, API con `http` nativo de Node.js y enrutador propio, base de datos PostgreSQL y microservicio de voz en Python. El código fuente del producto es privado; el repositorio público funciona como escaparate de documentación y capturas.

**Demo:** [play.clientesvip.es](https://play.clientesvip.es) · **Repositorio:** [github.com/IsraelLiraDev/bibliaplay](https://github.com/IsraelLiraDev/bibliaplay).
